# Contributing to Voice Order System

Thank you for your interest in contributing. By participating you agree to abide by the [Code of Conduct](CODE_OF_CONDUCT.md).

## Getting started

1. Fork the repository and create a feature branch.
2. Keep changes focused and small — one logical change per pull request.
3. Run `npm run check` and `npm test` before opening a pull request.
4. Update the README or deployment guide when you change configuration or behavior.

## Pull request checklist

- Describe the **problem** and the **behavior change** in the PR description.
- Include reproduction steps or test evidence.
- Do not remove failing checks to make a badge green.

## Reporting bugs

Use the issue templates and include:

- Steps to reproduce
- Browser and operating system
- Expected vs. actual behavior
- Any console errors

Do not post secrets, customer data, or personal phone numbers in issues.
