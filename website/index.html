Voice Flow

From "Hello" to confirmed order in 4 steps.

1. Wake & Greet

User clicks microphone. Alex (persona) greets: "Hi! I'm Alex. What can I get you today?" SpeechRecognition starts.

2. Natural Language

User speaks naturally: "Two large pepperoni, one coke, no ice." Web Speech API → text. Sent to LLM for intent parsing.

3. Confirm & Clarify

Alex reads back: "Two large pepperoni pizzas, one coke no ice. That's $28.50. Correct?" User says "Yes" or corrects.

4. Save & Notify

On confirmation, [SAVE_ORDER:{...}] block emitted. Supabase inserts order. Kitchen display updates. SMS sent if phone provided.

LLM Fallback Chain

Three-tier cascade. Automatic failover. Zero config if you have OpenRouter key.

llm_fallback.py
FALLBACK CHAIN (OpenRouter) ───────────────────────────────────── 1️⃣ PRIMARY: Mistral Nemo (12B) Model: mistralai/mistral-nemo:free Context: 128k tokens Strength: Instruction following, JSON mode Latency: ~800ms ↓ on error / timeout / rate limit 2️⃣ SECONDARY: Mistral 7B Instruct Model: mistralai/mistral-7b-instruct:free Context: 32k tokens Strength: Fast, reliable, good JSON Latency: ~400ms ↓ on error / timeout / rate limit 3️⃣ TERTIARY: Llama 3.1 8B Model: meta-llama/llama-3.1-8b-instruct:free Context: 128k tokens Strength: Robust, multilingual Latency: ~600ms ───────────────────────────────────── All models: FREE tier on OpenRouter Fallback: Automatic, < 2s switchover Config: OPENROUTER_API_KEY env var

Backend: Supabase

Orders table with RLS. Real-time subscriptions for kitchen display.

schema.sql
create table orders ( id uuid primary key default gen_random_uuid(), order_id text unique not null, -- ORD-7K9M2 customer_phone text, items jsonb not null, -- [{name, size, price, qty}] total_cents int not null, -- 1499 status text not null default 'pending', -- pending/confirmed/preparing/ready/completed persona text not null default 'alex', llm_model text, -- which model succeeded created_at timestamptz default now(), updated_at timestamptz default now() ); -- RLS: customers see own orders, staff see all alter table orders enable row level security; create policy "customer own" on orders for select using (auth.uid() = customer_id); create policy "staff all" on orders for all using (auth.jwt() ->> 'role' = 'staff'); -- Real-time for kitchen display alter publication supabase_realtime add table orders;

Test Suite (6 Hermetic Tests)

No network. No external APIs. Mocked SpeechRecognition, SpeechSynthesis, Supabase, OpenRouter.

test_greeting.py

Alex greets correctly. Persona loads. SpeechSynthesis called with expected text.

test_intent_parsing.py

LLM extracts items, sizes, modifiers. Handles "no ice", "extra cheese", quantities.

test_fallback_chain.py

Primary fails → secondary succeeds. Secondary fails → tertiary succeeds. All fail → graceful error.

test_save_order.py

[SAVE_ORDER:{...}] block emitted. Supabase insert called with correct shape. RLS respected.

test_limits.py

24 message cap enforced. 12 item cap enforced. $1000 cap enforced. Graceful rejection.

test_persona.py

Alex persona consistent. Tone: helpful, concise, confirms prices. No hallucination.
